# UI Foundry Typography System Generator

Standalone visual typography generator built with Next.js.

This app is a focused typography-building studio for heading systems, body scales, font direction, layout, effects, and preview-safe color systems that can be edited visually and exported as code.

## Product summary

This generator is designed for:

- designers building type systems for products, dashboards, and marketing pages
- developers who want editable typography tokens and previewable text styles
- freelancers and agencies preparing repeatable type direction for client work
- buyers who want a standalone typography system tool that matches the UI Foundry suite

## What the product includes

- section-based editing controls
- live preview panel
- code view with copy support
- file export support
- searchable preset library
- generated premium preset catalog with filters, paging, and surprise-me apply
- undo and redo controls
- self-contained standalone app structure

## Editing coverage

The editor currently includes these control areas:

- Presets
- Scale
- Headings
- Body
- Font Family
- Colors
- Spacing
- Layout
- Effects
- Accessibility

These sections cover typographic scale, heading roles, body roles, font choices, text and preview color systems, spacing behavior, layout direction and overflow handling, decorative effects, and accessibility-related controls.

## Export workflow

The typography preview and code output are driven from the same current system state so users can tune type visually and export the matching implementation.

## Why this product is useful

This is not just a font picker. It is a typography system builder for creating consistent text direction across product surfaces.
